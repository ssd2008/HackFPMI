# Тесты почтового поиска и синхронизации

Ветка основана на проверенной рабочей версии `b53eb5a`. Основные автоматические тесты находятся в [tests](../tests/), публичный VK — в [data](../data/), проверки поиска, ответов и задержки — в [tools](../tools/). [Итоговые замеры и команды](../docs/validation-round4.md). Для поиска по истории файлов [каталог](historical-tests.tsv) связывает путь и версию теста с конкретным коммитом. Получить исходник можно командой `git show КОММИТ:ПУТЬ`.

## Почтовая и внешняя валидация

[mail-ood-v1](mail-ood-v1/) содержит четыре почтовые выборки, панели, переформулировки, пустые запросы, qrels, RAG с проверкой источников и парные диагностические задания. Девять внешних снимков включают запросы, разметку и сжатый корпус каждого набора. Личные корпуса для запуска собираются на компьютере из исходных командных экспортов. Скрипт сверяет хеши с манифестами.

Из корня этой ветки в окружении проекта выполните:

```sh
python3 validation/mail-ood-v1/method/prepare.py --data data
python3 validation/mail-ood-v1/method/verify_suite.py
find validation -name '*.gz' -exec gzip -dkf {} \;
python3 validation/mail-ood-v1/method/verify_transfer.py --project .
```

## Предыдущие и сквозные проверки

[Архив](archive/) содержит исходные сценарии экспериментов, тестовые запросы, проверки под нагрузкой, тесты браузера и проверки публичного адреса. Часть одноразовых сценариев использует пути, порты и структуру `.cache` исходного Mac. Перед запуском таких сценариев проверьте их параметры. [search_bench](../search_bench/) содержит отдельный поисковый бенчмарк с перефразировками.

[release-tests](release-tests/) соответствует командной сборке `5d84737`, а [local-owner-tests](archive/local-owner-tests/) — прежней локальной сборке `4618075`. Их запускают на соответствующем коммите. Для текущей версии поднимите сервер на 8766 и выполните `MAILSEARCH_URL=http://127.0.0.1:8766 python3 -m unittest discover -s tests`. В сценариях синхронизации IMAP подменяется тестовым провайдером.
