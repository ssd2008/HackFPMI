# Разработка и публикация демо

- Работай в своей копии `HackFPMI`. Для незакоммиченных изменений поднимай локальный сервер на порту 8766. Отдельная копия `~/HackFPMI-preview` на том же Mac обслуживает командное демо и содержит актуальный `main`.
- После проверки и попадания изменения в `main` запусти `~/HackFPMI-preview/scripts/deploy_preview.sh`. Он обновит серверную копию, при необходимости перезапустит API и отправит фронтенд на Pages. Дождись деплоя и сверь `version.txt` с коммитом `main`. Проверь поиск и открытие письма.
- Фронтенд редактируй в `static/` приватного репозитория. `HackFPMI-demo` обновляется скриптом. Для публичного просмотра используй только исходный синтетический корпус VK. Файлы личной почты предназначены для локальных тестов.
- Установка на Mac, туннель и команды проверки описаны в [инструкции](README.md#командное-демо-на-github-pages).
