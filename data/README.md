# Умный поиск в Почте · данные хакатона

В корпусе 16376 псевдонимизированных писем. Публичный бенчмарк содержит 99 запросов и 565 связей релевантности.

## Файлы

| Файл | Поля |
| --- | --- |
| `documents.jsonl` | `doc_id`, `synthetic_user`, `doc` (текст письма), `doc_dt` (дата получения или `null`) |
| `queries_dev.jsonl` | `query_id`, `synthetic_user`, `query` (текст запроса), `query_date` (дата запроса) |
| `qrels_dev.jsonl` | `query_id`, `doc_id`, `relevance` (1 для релевантного письма) |
| `manifest.json` | Количество строк и контрольные суммы SHA-256 |

JSONL в UTF-8, один JSON-объект на строку. Даты имеют формат `YYYY-MM-DD`. Каждый запрос выполняется в почтовом ящике из `synthetic_user`. Дата запроса задаёт точку отсчёта для относительных периодов, включая «вчера». Письмо с известной датой получения после даты запроса ещё недоступно. `null` означает, что дата получения неизвестна.

Для локальной проверки можно посчитать Recall@K и nDCG@K по публичной таблице. MRR@K для поиска конкретного письма удобно считать по запросам с одним релевантным документом. Объекты без строки в таблице получают нулевую оценку при расчёте метрик. Итоговый замер организаторы проводят на закрытом бенчмарке. Требование к p99 бэкенда из постановки задачи — строго менее 1 секунды.

Тексты и даты синтетические. Контакты в примерах могут быть техническими заменами.

В этой версии уточнена разметка публичных запросов по письмам нужного ящика и дня.
